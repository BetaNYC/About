# Getting Support

Where to go depends on what you need.

## I found a bug or have a feature idea

Open an issue in the relevant repository using the issue templates. That keeps the discussion with the code and lets others find it later.

## I have a question about using a project

- Check the project's `README` first.
- If the answer is not there, reach the BetaNYC community at https://www.beta.nyc/links.

## I want to report a security vulnerability

Do not open a public issue. See `SECURITY.md`.

## I want to report a Code of Conduct concern

Contact the Safer Spaces Team at **saferspaces@beta.nyc**. See the [Code of Conduct](https://www.beta.nyc/code-of-conduct-anti-harassment-policy/).

## I want to get involved with BetaNYC

- Read `CONTRIBUTING.md` in any repository.
- Subscribe to our newsletter, *This week in NYC's #CivicTech*, at https://beta.nyc.
- Join the community at https://www.beta.nyc/links.

## A note on response times

BetaNYC is a small civic organization supported by staff and volunteers. We do our best to respond, and we appreciate your patience.
