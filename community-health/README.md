# BetaNYC Community Health Files (staging)

This folder holds BetaNYC's GitHub community health files: a Code of Conduct pointer, a contributing guide, a security policy, a support guide, and issue and pull request templates. Together they shape how people take part in BetaNYC's repositories.

Everything here is anchored in the **[BetaNYC Code of Conduct](https://www.beta.nyc/code-of-conduct-anti-harassment-policy/)**. The other files reference it rather than restating it.

## Status: staging

These files are being reviewed here first. When they are ready, they move to a dedicated public **`BetaNYC/.github`** repository. That is the repository GitHub reads to apply community health files across every BetaNYC repository automatically, and it is where the org profile page and the shared issue and pull request templates take effect. Until that move, the files in this folder render only here.

Some internal links point at the future `BetaNYC/.github` home and will resolve once that repository exists.
