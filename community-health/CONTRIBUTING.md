# Contributing to BetaNYC

Thank you for helping improve public technology for New York. This guide covers how to contribute to any repository in the BetaNYC organization. An individual project may add its own `CONTRIBUTING.md` with specifics; when it does, that file takes precedence.

## Before you start

By participating, you agree to the [BetaNYC Code of Conduct](https://www.beta.nyc/code-of-conduct-anti-harassment-policy/). It governs issues, pull requests, comments, and every other interaction here.

## Ways to contribute

You do not have to write code to help.

- **Report a problem.** Open an issue using the templates. Tell us what you expected and what happened.
- **Suggest an idea.** Open an idea issue. Early feedback saves everyone time.
- **Improve the docs.** Fixing a confusing README or a broken link is a real contribution.
- **Write code.** See the workflow below.

## Filing a good issue

- Search open issues first so you do not file a duplicate.
- One issue per problem or idea.
- Include steps to reproduce, the URL or file involved, and any error text.
- Do **not** file security vulnerabilities as public issues. See `SECURITY.md`.

## Pull request workflow

1. Fork the repository and create a branch from the default branch.
2. Make your change. Keep it focused; smaller pull requests are reviewed faster.
3. If the project has tests or a linter, run them.
4. Open a pull request and fill out the template. Link the issue it addresses.
5. A maintainer will review. Expect a conversation; civic projects are collaborative by design.

## Licensing of your contribution

BetaNYC builds in the open so the work is free for New Yorkers to reuse. Unless a repository states otherwise, **code is licensed under the MIT License**, and **documentation, text, and data under Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)**. By opening a pull request, you agree that your contribution may be distributed under those terms.

## Questions

If you are unsure where to begin, see `SUPPORT.md` or reach the community at https://www.beta.nyc/links. We would rather answer a question than have you feel stuck.
