# What's changed

This page lists the changes to this repository, BetaNYC's public copy of its organizational policies: when a new version of a policy was copied in, when a policy was retired, and changes to how the repository is organized. Newest first. It does not retell what changed inside a policy. Each policy says that itself, and older versions are kept in [policies/archive/](policies/archive/).

- **History begins:** 2014-07-16, when the first policy, the Code of Conduct, was added. The repository started in 2013 as an "about" page and a collection of logos; changes before 2014-07-16 are not listed, and corrections made before then may be missing.
- **Data refresh:** none on a schedule. A policy is copied in by hand after it is published on beta.nyc, which is the official version.

There is no separate website for this page: this file on GitHub is the page. To report a mistake in this repository or ask for a change, [open an issue on GitHub](https://github.com/BetaNYC/About/issues).

## 2026-07-19: The Privacy Policy showed the wrong revision date

- **Tags:** Site, Correction
- **What changed:** For about 80 minutes after version 2.2 was copied in, shortly after midnight, the copy here said "Last revised: July 18, 2026". The date of that version is July 19, 2026, and the copy was corrected.
