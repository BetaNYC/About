# BetaNYC Policies

This folder is the public, versioned home for BetaNYC's organizational policies. Each policy is tracked in git, so anyone can read the current version, see how it has changed over time, and reuse it.

Where a policy is published on our website, that page is the canonical version for the public; the file here mirrors it. The full text of each policy lives in the file — the table below is an index.

## Licensing and reuse

Except where a file states otherwise, the policies here are licensed **CC BY-SA 4.0** (see the repository [LICENSE](../LICENSE)). You are welcome to adapt them for your own organization — attribution and share-alike apply. If you build on the privacy policy, we'd love to hear about it.

## How these files stay current

BetaNYC drafts and reviews its policies internally, then publishes them to the website and mirrors the published text here. When a policy is revised and republished, the file in this folder is updated in the same pass, so the git history tracks each published revision.
